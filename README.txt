JESSE — PERSONAL PORTFOLIO WEBSITE

Preview:
Open index.html in a modern browser. No installation or build step is needed.

Before publishing:
1. Replace YOUR_EMAIL@example.com in index.html with your public contact email.
2. Replace the photo placeholder with your own portrait.
3. Add social/profile links if you want them public.
4. Review project descriptions and update progress as work evolves.

Publishing:
Upload index.html to a static hosting provider (for example, GitHub Pages, Netlify, or Cloudflare Pages) or to your web host's public web directory.
A custom domain can be connected after you choose and register an available domain name.
